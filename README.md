# Play Taiwan 路線展示（Flutter）

錄製測試畫面用的 Flutter App，連 System 後端（預設 `http://localhost:5501`）。

## 畫面

| 分頁 | 內容 |
|---|---|
| 劇本交通路線 | 要去的地方選「劇本」或「同心圓」（點地圖設中心，畫出 10/20/30 分鐘可到達範圍，隨機抽 8 個景點）→ 勾交通方式（沒有公車/捷運的區域反灰）→ 規劃去程 + 返程。每種交通方式有自己的顏色、線型、圖示；沿線箭頭標方向（實心 = 去程、空心 = 返程）；點一段可放大並切換其他交通方式。劇本模式下地圖也標出劇本周邊好去的地點（金色 = 飲食、綠色 = 景點與其他），右上角切換「飲食／周邊好去（全部）／其他」，點標記看票券卡片，「前往地址」開 Google Maps |
| 公車站牌 | 點地圖找附近站牌 → 即時到站 → 路線線形、站牌、發車時間；台灣好行路線列表 |

| 交通方式 | 地圖上的樣子 |
|---|---|
| 步行 | 綠色點線 |
| 腳踏車 | 橘色虛線 |
| 機車 | 紫色長短虛線 |
| 汽車 | 深灰實線 |
| 公車 | 紅色實線＋白框，標出經過的站牌 |
| 捷運 | 該路線代表色實線＋白框，標出經過的車站，轉乘站會拆成兩段 |

## 執行

```bash
flutter pub get
flutter run -d chrome    # 網頁（建議用這個錄影，已實測可用）
flutter run              # Android 模擬器（後端網址會自動用 http://10.0.2.2:5501）
```

錄影時把 Chrome 視窗拉寬（≥ 900px）會是「左地圖、右面板」；拉窄成手機寬度會變成「上地圖、下方拉起面板」。

實機測試時，登入頁的「後端網址」改成電腦的區網 IP，例如 `http://192.168.1.10:5501`。

## 測試資料

先在 MySQL 依序匯入 `System/Sqls/mysql/` 裡的：

1. `CreateMetroTables.sql`：捷運資料表
2. `MetroData.sql`：全台捷運 / 輕軌
3. `BusData_Taichung.sql`：臺中公車 + 台灣好行（後端已經同步過就不用）
4. `TestData_RouteDemo.sql`：景點座標 + 3 個測試劇本（檔案開頭的 `@au_id` 改成自己的帳號）
5. `TestData_Nearby.sql`：周邊好去用的飲食／其他地點（照片先留空，營業時間與座標為展示用）

## 注意

專案路徑有中文（桌面\題目\…）時：

- `flutter run -d chrome`、`flutter build web` 正常。
- `flutter analyze` 的分析伺服器會當掉，`flutter build windows` 也會失敗（MSBuild 把中文路徑轉成亂碼）。
  要跑這兩個，請把專案整個搬到純英文路徑，例如 `C:\dev\play_taiwan_demo`。
